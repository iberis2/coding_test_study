# 영어 끝말잇기

## 문제 설명

n명의 사람이 순서대로 영어 끝말잇기를 진행한다.

각 차례에서 다음 규칙을 지켜야 한다.

1. 이전 단어의 **마지막 문자**로 시작해야 한다.
2. **이미 사용된 단어는 사용할 수 없다.**

**순서대로 단어를 검사하면서 처음으로 규칙 위반한 사람의 번호와 차례**를 찾는 문제

## 문제 규칙

1. 사람 번호는 **1 ~ n**
2. 단어는 **순서대로 words 배열에 저장**
3. 실패 조건\
  3-1. 이전 단어 마지막 문자 ≠ 현재 단어 첫 문자\
  3-2. 이미 사용된 단어
4. 실패한 위치 i에서\
사람 번호 = (i % n) + 1\
차례 = Math.floor(i / n) + 1


## 수도코드
* **Set / HashMap**으로 등장 단어 관리
* 순회하면서 규칙 위반 즉시 return

```
1. 사용한 단어를 저장할 Set 생성
2. 첫 번째 단어를 Set에 저장

3. i = 1부터 words 끝까지 반복

    3-1. 이전 단어 마지막 문자 확인
    3-2. 현재 단어 첫 문자 확인

    if
        이미 등장한 단어
        OR
        이전 단어 끝 문자 ≠ 현재 단어 시작 문자
    then
        사람 번호 계산
        차례 계산
        return [사람번호, 차례]

    현재 단어를 Set에 저장

4. 끝까지 문제 없으면
   return [0,0]
```

## 1. HashMap / Set

단어 중복 여부를 O(1)로 확인

## 2. 노드 생성 / 전처리

첫 단어를 미리 저장

```javascript
const dic = { [words[0]]: words[0] };
```

또는 Set 사용 가능

```javascript
const set = new Set([words[0]]);
```

---

## 3. 조건 검사

단어를 순서대로 검사하면서 **2가지 조건 확인**
```
1. dic[words[i]] → 이미 등장한 단어
2. words[i-1].at(-1) !== words[i][0]
   → 끝말잇기 실패
```

```javascript
if (dic[words[i]] || words[i - 1].at(-1) !== words[i][0]) {
```


## 4. 탈락자 계산

```javascript
const person = (i % n) + 1;
const count = Math.floor(i / n) + 1;
```

예시

```
n = 3

index: 0 1 2 3 4 5 6 7 8
player:1 2 3 1 2 3 1 2 3

i = 8

person
= (8 % 3) + 1
= 3

count
= Math.floor(8 / 3) + 1
= 3
```

→ **3번 사람이 3번째 차례**


## 시간 복잡도

### 단계별 시간복잡도

| 단계    | 연산         | 복잡도  |
| ----- | ---------- | ---- |
| 단어 순회 | words 순회   | O(n) |
| 중복 확인 | HashMap 조회 | O(1) |
| 문자 비교 | 문자열 접근     | O(1) |

---

### 전체 시간복잡도

O(n)\
words 최대 100
