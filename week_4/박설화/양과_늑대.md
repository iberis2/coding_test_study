# 양과 늑대 (Programmers 92343)

## 문제 설명

이진 트리 형태의 초원에서 **양(0)** 과 **늑대(1)** 가 각각 한 마리씩 존재한다.
루트 노드(0번)에서 시작하여 여러 노드를 방문하면서 **양을 최대한 많이 모으는 것**이 목표이다.

단, **늑대의 수가 양의 수 이상이 되는 순간 모든 양이 잡아먹힌다.**

따라서 다음 조건을 항상 만족해야 한다.

```
sheep > wolf
```

가능한 경로 중 **모을 수 있는 양의 최대 개수**를 구하는 문제이다.


## 문제 규칙

1. 트리는 **이진 트리 구조**
2. 노드 정보

   * `0 → 양`
   * `1 → 늑대`
3. 루트 노드(0번)는 항상 양
4. 이동 규칙

   * 부모 → 자식으로 DFS 로 탐색하지만
   * 이미 방문한 노드의 자식이면 언제든 이동 가능
   * 예시
      ```
      0 → 1 → 8 → 4
      ```

5. 실패 조건\
늑대 >= 양  → 모든 양이 잡아먹힘

6. 목표: 양의 최대 개수

###  문제 특이사항
일반 DFS : 현재 노드 → 자식 노드 로만 가능하지만

여기서는 현재까지 방문한 노드의 자식들 = 언제든 갈 수 있는 후보 노드이므로 **DFS 트리 탐색을 하면서 "방문 가능한 노드 후보 집합" 관리** 해야한다.

### 탐색 상태

각 DFS 상태는 다음 정보를 가진다.

현재 노드\
현재 양 수\
현재 늑대 수\
현재 이동 가능한 후보 노드 목록


### 탐색 방식

1. 현재 노드 방문
2. 양 / 늑대 카운트 증가
3. 늑대 >= 양이면 탐색 중단
4. 최대 양 갱신
5. 후보 노드 목록에서 다음 노드를 선택하여 DFS

## 수도코드

```js
graph 생성 (부모 → 자식)

DFS(node, sheep, wolf, candidates)

    현재 노드가 양이면 sheep++
    늑대면 wolf++

    if wolf >= sheep
        return

    answer = max(answer, sheep)

    for 후보 노드 nextNode in candidates

        다음 후보 노드 목록 생성
            candidates에서 nextNode 제거
            nextNode의 자식 노드 추가

        DFS(nextNode, sheep, wolf, nextCandidates)
```

---

## 코드 설명
### 1. 데이터 구조

```js
const graph = Array.from({length: info.length}, () => []);
```

트리 구조를 **인접 리스트**로 저장한다.

```
graph[parent] = [child1, child2]
```


### 2. 노드 생성 / 전처리

```js
edges.forEach(([p, c]) => {
    graph[p].push(c);
});
```

부모 → 자식 방향으로 그래프 생성

예시

```
0
├─ 1
│  ├─ 2
│  └─ 4
└─ 8
```

---

### 3. 핵심 알고리즘

DFS + **후보 노드 관리**

```js
function dfs(curNode, sheep, wolf, candidates){
    info[curNode] ? wolf++ : sheep++;

    if(wolf >= sheep) return;

    answer = Math.max(answer, sheep);

    for(let nextNode of [...candidates]){
        const nextCandidates = [
            ...candidates.filter(n => n !== nextNode),
            ...graph[nextNode]
        ];

        dfs(nextNode, sheep, wolf, nextCandidates);
    }
}
```

현재 갈 수 있는 노드 후보를 계속 업데이트 :

기존 후보 - 현재 이동한 노드 제거 + 그 노드의 자식 노드 추가


---

### 4. 순회 또는 계산 과정

예시 탐색 흐름

```
start: 0
sheep = 1
candidates = [1,8]
```

탐색 예시

```
0 → 1
sheep=2 wolf=0
candidates = [8,2,4]

0 → 1 → 8
sheep=2 wolf=1
candidates = [2,4,7,9]
```

이렇게 **가능한 모든 경로를 DFS로 탐색**한다.


## 시간 복잡도
### 그래프 생성
edges 순회 O(N)

### DFS 탐색

노드 수 N ≤ 17


각 노드 선택 여부
- 최대 2^N


DFS 상태

```
양/늑대 조건으로 많이 pruning
```

---

### 전체 시간복잡도
O(2^N)
- N ≤ 17

---
### 구현 시 주의할 점

**candidates 복사 필수**

```js
[...candidates]
```

안 하면 DFS 상태가 공유됨

**늑대 ≥ 양이면 즉시 종료**

```js
if(wolf >= sheep) return;
```

**다음 후보 생성**

```
현재 노드 제거
+ 자식 노드 추가
```
