
## 문제 설명
이 문제는 다단계 판매 구조, 부모 방향으로 올라가는 트리 문제입니다.
```
판매자 → 추천인 → 추천인의 추천인 → ... → center('-')
```

수익 분배 규칙
```
- 판매금액의 10% → 추천인에게 전달
- 나머지 90% → 본인이 가짐
```
조건
```
- 10%가 1원 미만이면 더 이상 전달하지 않음
- 추천인이 '-' 이면 종료
```

## 수도코드

 1. 판매원 정보를 저장 {name, money, ref}
 2. name → index map 생성 {name: index}\
   2-1. 이름을 바로 index로 변환해야 O(1) 접근 가능
 3. seller, amount(판매 금액) 배열을 순회
 4. 각 판매에 대해 수익 분배(판매원 정보의 money 에 수익 추가) 실행 → 재귀 or 반복문
 5. 판매원 정보에서 money 배열만 반환 

 ## 특이사항
 ```js
  const sellerIdx = queue.findIndex(el => el.name === seller);
  const nameToIndex = {}; 
 ```
  findIndex 로 했을 때에도 O(N) 이지만\
  N = enroll.length 최대 = 10,000 → O(depth × N) = 10,000 × 10,000= 100,000,000 이므로\
  시간 초과가 발생하여 해시맵 O(1)으로 변경
  

 ## 시간 복잡도
 한 번의 판매 처리 : O(depth) 
   - enroll 최대 = 10,000 이지만 10% 로 줄어드므로 depth ≈ log10(10000), 10 이하

 전체 시간 복잡도 : O(Seller 길이 * depth)
  - seller의 길이는 1 이상 100,000 이하
  - 최악 : O(100,000 * 10) → O(1,000,000)

## 풀이 1. 재귀
```js
function solution(enroll, referral, seller, amount) {
  const queue = [];
  const nameToIndex = {}; 
  
  enroll.forEach((name, idx) => {
      queue.push({name, money: 0, ref: referral[idx] })
      nameToIndex[name] = idx;
  });

  
  for(let i = 0; i < seller.length; i++){
      distributeProfit({money: amount[i] * 100, seller: seller[i]})
  };

  /**
   * 재귀 흐름
   * 1. 현재 판매자에게 90% 지급
   * 2. 10% 계산
   * 3. 추천인에게 다시 호출
   * 재귀 종료 조건 : 
   * seller === '-' || money === 0
   */
  function distributeProfit({money, seller}){
      if(seller === '-' || money === 0) return;
      
      const commission = Math.floor(money * 0.1);
      const profit = money - commission;
    
      const sIdx = nameToIndex[seller];
      queue[sIdx].money += profit;
      return distributeProfit({ money: commission, seller: queue[sIdx].ref});
  }
  
  return queue.map(el => el.money);
}
```
## 풀이 2. while 문
재귀는 함수 호출 비용(call stack push/pop)이 발생하지만\
while 는 단순 반복이므로 stack 사용 없어서 더 빠름
```js
function solution(enroll, referral, seller, amount) {
  const queue = [];
  const nameToIndex = {};
  
  enroll.forEach((name, idx) => {
      queue.push({name, money: 0, ref: referral[idx] })
      nameToIndex[name] = idx;
  });

  
  for(let i = 0; i < seller.length; i++){
      distributeProfit({money: amount[i] * 100, seller: seller[i]});
  };
  
/**
 * while 풀이 설명
 * seller가 존재하고 money > 0
 * 반복 : seller → parent → parent → ...
 * 구조 : while(seller !== '-' && money > 0)
 */

  function distributeProfit({money: _money, seller: _seller}){
      let money = _money, seller = _seller;

      while(seller !== '-' && money > 0){
          const commission = Math.floor(money * 0.1);
          const profit = money - commission;
          
          const sIdx = nameToIndex[seller];
          queue[sIdx].money += profit;

          money = commission;
          seller = queue[sIdx].ref;
      }
      
  }
  
  return queue.map(el => el.money);
}
```
