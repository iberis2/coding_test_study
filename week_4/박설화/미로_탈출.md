# 미로 탈출 (Programmers 159993)

## 문제 설명

격자 형태의 미로에서 **출발점(S) → 레버(L) → 출구(E)** 순서로 이동하여 탈출해야 한다.

* 벽(`X`)은 통과 불가
* 통로(`O`)는 이동 가능
* 출구(`E`)는 **레버를 당기기 전에도 지나갈 수 있음**
* 이동 1칸 = 1초

최소 시간으로 탈출하는 시간을 구하는 문제

## 문제 규칙
1. S → L → E 순서로 이동해야 탈출 가능
2. 벽(X)은 이동 불가
3. 상하좌우 4방향 이동 가능
4. 모든 칸은 여러 번 지나갈 수 있음
5. 탈출 불가능하면 -1 반환

## 수도코드
격자에서 **최단 경로**를 구하는 문제이므로 **BFS(너비 우선 탐색)** 를 사용

- DFS는 최단 거리 보장이 없고 BFS는 **레벨 단위 탐색**이기 때문에 처음 도달한 경로가 최단 거리


반드시 레버를 먼저 당겨야 하므로\
`S → L 최단 거리` + `L → E 최단 거리` 두 BFS 결과를 각각 구해서 합하여 최종 거리를 구함

만약 둘 중 하나라도 갈 수 없다면 **탈출 불가능(-1)**

---
1. maps 전체를 탐색해서
   - 시작 위치 S
   - 레버 위치 L
   - 출구 위치 E
   를 찾는다

2. BFS(start → lever)
   - 이동 불가능하면 return -1

3. BFS(lever → exit)
   - 이동 불가능하면 return -1

4. 두 거리 합을 반환

## 1. 데이터 구조

```
queue : BFS 탐색용
visited : 방문 체크 2차원 배열
[y, x, dist] : 현재 위치와 이동 거리
```

- 격자 크기 : 최대 100 x 100


## 2. 노드 생성 / 전처리

전체 맵을 순회하며 **S / L / E 위치 찾기**

```javascript
for (let y = 0; y < maps.length; y++){
  for(let x = 0; x < maps[y].length; x++){
      if(maps[y][x] === 'S') start = [y, x];
      else if(maps[y][x] === 'L') lever = [y, x];
      else if(maps[y][x] === 'E') exit = [y, x];
  }
}
```

## 3. 최단 거리 탐색 BFS
```
queue에 시작 위치 넣기
while(queue)
    현재 위치 pop

    목표 위치이면 거리 반환

    4방향 탐색
        범위 안이고
        벽이 아니고
        방문하지 않았으면
            queue에 추가
```

## 4. 순회 또는 계산 과정

```
S → L BFS
↓
최단 거리 = 4

L → E BFS
↓
최단 거리 = 12

총 시간 = 16
```
