
## 문제 설명
좌표로 이진트리를 만드는 문제

## 문제 규칙

```
1. y → 트리 레벨
- 부모 노드는 항상 자식보다 y가 큼
2. 서브트리 x < 부모 x → 왼쪽에 연결
3. 서브트리 x > 부모 x → 오른쪽에 연결
```

## 수도코드

```
1. y 기준으로 정렬해서 루트부터 만든다
2️. x 기준으로 이진트리처럼 삽입한다
3️. preorder / postorder 순회
```


###  노드 생성 & 정렬

```javascript
// 노드 생성 { x, y, index }
nodeinfo.map(([x, y], idx) => ({ x, y, index: idx + 1})) 

/** 노드 정렬
 1️. y 내림차순
 2️. x 오름차순
 */
.sort((a,b)=> b.y - a.y || a.x - b.x)

/**
(x,y)
(8,6)
(3,5) (11,5)
(1,3) (5,3) (13,3)
 * /
```


### 트리 생성 알고리즘

1) 첫 번째 노드 -> root
2) 이후 노드는 x 기준으로 이진트리로 삽입


```javascript
insert(node){
  if(node.x < this.x){
      left
  } else {
      right
  }
}
```

예시

```
       (8,6)
       /   \
   (3,5)  (11,5)
```

---

### 순회 알고리즘

### Preorder (root → left → right)

```javascript
arr.push(node.index);
preorder(node.left)
preorder(node.right)
```

---

### Postorder (left → right → root)

```javascript
postorder(node.left)
postorder(node.right)
arr.push(node.index)
```



## 시간 복잡도

### 정렬

노드 수 : N ≤ 10,000\
정렬 : O(N log N)

### 트리 삽입

각 노드 삽입 : O(height)
문제 조건 :
- 트리 depth ≤ 1000
- 최악 O(N × height) → 10,000 × 1000 = 10,000,000

### 트리 순회
O(N)

### 전체 시간 복잡도


O(N log N + N × height)
- 최악 : O(10^7)
