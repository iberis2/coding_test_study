# 전화번호 목록

## 문제 설명

전화번호 목록에서 **어떤 번호가 다른 번호의 접두어(prefix)** 인 경우가 있는지 확인하는 문제

예시

```
119
1195524421
```

`119`는 `1195524421`의 **접두어**이므로 조건에 위배

조건을 만족하지 않으면 `false`, 모두 문제 없으면 `true` 반환


## 문제 규칙

1. 전화번호가 다른 전화번호의 **접두어(prefix)** 가 되면 안 된다.
2. phone_book 길이

   * 최대 **1,000,000**
   * **O(n²)** 풀이는 시간초과될 수 있음
3. 전화번호 길이

   * 최대 **20**


## 수도코드
```
1. phone_book을 정렬한다
    - 정렬하면 접두어 관계에 대해 항상 바로 다음 원소와만 비교므로 전체 비교 필요 없음
2. phone_book을 앞에서부터 순회한다
3. 현재 번호를 next 번호와 비교한다
4. next가 current로 시작하면
      false 반환

5. 끝까지 문제 없으면 true 반환
```

## 3. 정렬 된 상태에서 현재 번호가 다음 번호의 prefix인지 확인

조건 성립하면 바로 `false`

```js
if(phone_book[i+1].startsWith(phone_book[i])) return false
```

### 예시

```
["119", "97674223", "1195524421"]
```

정렬

```
["119", "1195524421", "97674223"]
```

순회

```
i=0
119
1195524421

startsWith → true
```

즉시 종료

```
return false
```

## 시간 복잡도

### 정렬

O(n log n)


### 접두어 검사

O(n)

각 비교에서 `startsWith`는 최대 20자 비교
O(20) ≈ O(1)

### 전체 시간복잡도

O(n log n)

n 최대 **1,000,000**
